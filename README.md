# dsh-roost-personas

`dsh-roost`（DSH 的 QQ 机器人宿主插件）用的人格库。一个人格一个 Markdown 文件，
丢进目录就能用，不需要改代码、不需要发版。

- 上游：[tdcq9594/dsh-roost](https://github.com/tdcq9594/dsh-roost) 的 `personas/` 目录
- 本仓库是它的**独立分发点**：内容一致，改了上游再同步过来

## 包含哪些

| 文件 | 名字 | 风格 |
|---|---|---|
| `default.md` | 小栖 | 话不多但有意思，默认人格 |
| `fatfish.md` | 大肥鱼 | 短句、爱吐槽（只损事不损人）、不装真人 |
| `genki.md` | 元气 | 活泼、感叹号多、爱起哄 |
| `helper.md` | 助手 | 有条理、先给结论再给步骤 |
| `scholar.md` | 学者 | 严谨、爱补背景、会说「不确定」 |
| `snarky.md` | 毒舌 | 嘴损、爱反问，但不真伤人 |
| `teacher.md` | 老师 | 循循善诱、举例子、会追问掌握没 |
| `terse.md` | 惜字如金 | 一句话能说清就绝不用两句 |

`index.json` 是索引（`file` → `sha256` + 分片 `packs/`），给 `dsh-roost` 面板的
「从仓库更新」用。**别手改**，改完人格跑一次索引脚本。

## 怎么用

**面板更新**（推荐）：`dsh-roost` 面板 →「人格」→「从仓库更新」。
它只对比 `index.json` 的 sha256，只下载变过的那几份。

**手动安装**：把人格文件复制到 DSH 数据目录下的 `personas/`：

```
Windows   %USERPROFILE%\.dsh\dsh-roost\personas\
macOS/Linux  ~/.dsh/dsh-roost/personas/
```

放进去了不用重启，面板刷新一下就能看到。文件名就是 id，**别和别人撞名**——
装别人的 `fatfish.md` 会盖掉你自己的。

## 写一个自己的

```markdown
---
label: 显示名
tags: 标签1, 标签2
---
正文：这个人是什么性格、怎么说话、有什么禁区。

## 开场白
（可选）主动搭话时的第一句风格。

## 说话示例
用户：今天加班到十点
你：辛苦了。吃了吗

## 世界书
（可选）触发词1, 触发词2 | 命中关键词时才注入的内容
```

四段都是可选的，只有正文是必需的。`## 世界书` 的格式是「命中词 | 内容」，
一行一条——命中才注入，用来放「这个群的梗」「某个人的设定」这类不该常驻的东西。
